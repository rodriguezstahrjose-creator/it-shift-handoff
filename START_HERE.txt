TO TRY IT
1. Extract the ZIP completely; do not run files from inside the ZIP viewer.
2. On Mac, double-click Start_Handoff.command. If it opens as text, open Terminal
   in this project folder and run: bash Start_Handoff.command
3. On Windows with Python 3.11+, double-click Start_Handoff.bat.
4. First setup installs the required packages and prints demo credentials.
   Username: technician. Save the password printed on that first run.
5. Open http://127.0.0.1:5055 in your browser. Keep the terminal window open.

If setup fails, see README.md for manual setup and Python version requirements.
First setup needs internet access; normal application use is local and offline.
